# Beekeepers-Journal
В этом приложение есть баги если вы их найдете пишите в telegram @Marcy_Alien

Это приложение предназначено для удобного ведения пасеки и организации основных процессов пчеловодства.

Оно позволяет собирать, хранить и систематизировать информацию о пчелиных семьях, получаемой продукции и деятельности пасеки. Все необходимые данные можно вести в одном месте, что помогает упростить учёт и сделать работу более организованной.

Основные возможности приложения:
- Ведение журнала учёта пчелиных семей.
- Просмотр информации о семьях и их происхождении.
- Учёт полученной продукции.
- Календарь пчеловода для отслеживания дат и задач.
- Ведение записей о доходах и расходах.
- Просмотр и хранение истории записей.

Приложение объединяет несколько инструментов, которые помогут пчеловоду систематизировать информацию, следить за состоянием пасеки и удобнее организовывать свою деятельность.
